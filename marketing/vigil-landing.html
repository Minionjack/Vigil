This is a concept. Should it be real?

Vigil isn't a shipping product — it's a prototype exploring what proactive AI coaching could feel like.

Vigil is a concept prototype, not a real product. The chat in section 03 calls Claude in real time and generates genuine responses; every metric, message, and profile elsewhere on this page is illustrative sample data — not real tracking, and not medical, nutrition, or fitness advice. The live demo works when this page is opened inside Claude's artifact viewer; opened as a plain downloaded file in a browser, the chat call will fail since it relies on Claude's API proxy.
